# Contributing

1. Fork, branch, make your change.
2. Run `python3 smoke_test.py` (or `pytest tests/test_smoke.py`). It is offline and must pass with **no** engine installed; install one engine (`pip install -r requirements-playwright.txt`, or `-selenium` / `-puppeteer`) to exercise its code too.
3. **If you touched `ad_parser.py`**: every parser check runs on real logged-out captures in `tests/fixtures/` (keyword searches in the US and Germany, one advertiser's ads, a political-ads search, a search with no results, a page captured before it painted, a single-ad link, one scroll batch, and one ad-details request with its answer). If the library changed shape, save a capture of what it serves now next to them — trimmed to the shell and the one results block, with session tokens removed and political-ad disclosure contacts replaced by placeholders — update the parser to match, and add a `smoke_test.py` check against the new fixture. Don't change the parser on a guess without a capture behind it.
4. Keep the three engines behaving identically: same exit codes, same `Product` schema, same CLI flags. The fetch logic itself lives once in `page_flow.fetch_search()`; an engine only supplies its driver's own page operations. If one engine has to diverge (see `selenium_scraper.py`'s CDP-credential limitation), say why in a comment.
5. Open a PR. CI runs the offline suite on two Python versions, builds the wheel and the Docker image, and runs one `engine-smoke` job per engine in its own virtualenv. A daily `canary` job runs one live search for 100 ads (the embedded batch plus 7 scrolls) through a residential proxy when the repo has the `FACEBOOK_PROXY` secret (see `TESTING.md`).

Bug reports and feature requests: open an issue. Please include the exact command you ran (without credentials) and the `.meta.json` sidecar from the run — or say that none was written, which is itself informative (see `output_writer.finish_run`). If a search came back blocked, stalled or empty, a `--dump-html` capture is the most useful thing you can attach.
